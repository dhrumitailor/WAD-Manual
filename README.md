# Web Development Practicals

This repository contains the practical implementations for HTML, CSS, and responsive web development.

## Practical Set 1: Student Resume Website

### Objective

Develop a professional personal resume website using only HTML.

### Tasks Covered

* Created a homepage using HTML5 semantic elements.
* Added Education, Skills, Projects, Certifications, and other sections.
* Created a separate Contact page using HTML forms.
* Included multimedia such as a profile image and video.
* Added map and social media links.
* Used tables to display educational information.
* Used hyperlinks for navigation and external resources.
* HTML pages can be validated using the W3C Validator.

### Concepts Covered

* HTML5
* Semantic Elements
* Tables
* Forms
* Multimedia
* Hyperlinks

## How to Run

1. Download or clone this repository.
2. Open the required practical folder.
3. Open `index.html` in a web browser.
4. Make sure the required images, videos, and CSS files are kept in their respective folders.
5. For Practical 3, an internet connection is recommended because Bootstrap is loaded through a CDN.
